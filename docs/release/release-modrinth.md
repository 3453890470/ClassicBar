# Classic Bar Unofficial

A maintained fork of Tfarcenim's Classic Bar — replaces vanilla HUD icon rows with classic-style progress bars, now with extended mod support.

## 🔌 Compatible Mods

- **Thirst** — [Thirst Was Taken](https://modrinth.com/mod/thirst-was-taken)

- **Vampire** — [Vampirism](https://modrinth.com/mod/vampirism)

- **Effects**
  - [Farmer's Delight](https://modrinth.com/mod/farmers-delight)
  - [Kaleidoscope Cookery](https://modrinth.com/mod/kaleidoscope-cookery)
  - [Enigmatic Legacy+](https://modrinth.com/mod/enigmatic-legacy-plus)

## ✨ What's New

- **Thirst overlay** — thirst bar for [Thirst Was Taken](https://modrinth.com/mod/thirst-was-taken)
  - Hydration sub-bar & drink preview

- **Vampirism blood bar** — vampire level bar rendering

- **Enigmatic Legacy+ compat** — Forbidden Curse hunger overlay

- **Farmer's Delight** — Nourishment overlay
- **Kaleidoscope Cookery** — Satiated Shield overlay

- **Debug tools** — 8 toggles for HUD rendering tests (dev only)

- **Full Chinese localization** — 完整中文翻译

- **Code refactoring** — cleaner preview rendering
  - Unified dependency declarations
