# Classic Bar v1.4.0 — Thirst Overlay Support

Classic Bar now supports **thirst (hydration) overlays**! 

## ✨ New Features

### 🧊 Thirst Bar
- Displays a thirst bar when **Thirst Was Taken** or **Tough As Nails** is installed
- Sub-bar shows quench/hydration level (similar to saturation bar)
- Drink preview shows expected thirst restoration when holding drinkable items

### 🔧 Debug Tools
- 8 debug toggles for testing bar rendering effects (Wither, Poison, Frozen, Hunger, Nourishment, Satiated Shield, Vampire, Forbidden Curse)
- Only active in development environment

### 🌐 Localization
- Full Chinese translation (中文完整本地化)
- Consistent naming: "解渴值" (quench value)

## 📦 Dependencies
- **Required:** NeoForge 21.1.228+
- **Optional:** Thirst Was Taken, Tough As Nails, Vampirism, Farmer's Delight, Kaleidoscope Cookery, Enigmatic Legacy+

## ⚙️ Configuration
New config entries for thirst bar colors, hydration bar display, drink preview toggle, and debug section.
