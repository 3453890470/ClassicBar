# Classic Bar Unofficial v1.4.0

**Classic Bar Unofficial** is a maintained fork of [Tfarcenim's Classic Bar](https://github.com/Tfarcenim/ClassicBar) — replaces vanilla HUD icon rows with classic-style progress bars, now with extended mod support.

## 🔌 Optional Compatibilities

- **Thirst** — [Thirst Was Taken](https://modrinth.com/mod/thirst-was-taken)
- **Vampire** — [Vampirism](https://curseforge.com/minecraft/mc-mods/vampirism-become-a-vampire)
- **Effects** — [Farmer's Delight](https://modrinth.com/mod/farmers-delight) · [Kaleidoscope Cookery](https://modrinth.com/mod/kaleidoscope-cookery) · [Enigmatic Legacy+](https://modrinth.com/mod/enigmatic-legacy-plus)

## ✨ What's New (vs. Original)

- **Thirst overlay** — thirst bar for [Thirst Was Taken](https://modrinth.com/mod/thirst-was-taken), with hydration sub-bar & drink preview
- **Vampirism blood bar** — vampire level bar rendering
- **Enigmatic Legacy+ compat** — Forbidden Curse hunger overlay
- **Farmer's Delight / Kaleidoscope Cookery** — Nourishment & Satiated Shield visuals
- **Debug tools** — 8 toggles for HUD rendering tests (dev only)
- **Full Chinese localization** — 完整中文翻译
- **Code refactoring** — cleaner preview rendering, unified deps

## 📦 Requires

NeoForge **21.1.228+**
