# Classic Bar v1.4.0

## Description
Classic Bar replaces the vanilla HUD icon rows with classic-style progress bars. This update adds **thirst overlay support**!

## What's New in v1.4.0

### 🔥 Thirst Overlay
When Thirst Was Taken or Tough As Nails is installed, Classic Bar will display a thirst bar replacing the food bar position. Features:
- Thirst level bar with configurable colors
- Hydration sub-bar (quench level)
- Drink preview when holding thirst-restoring items
- Configurable layout position

### 🛠 Debug Section
New debug configuration section for testing:
- Apply status effects periodically (Wither, Poison, Frozen, Hunger)
- Apply mod effects (Nourishment, Satiated Shield)
- Toggle Vampire level / Forbidden Curse

### 🐛 Bug Fixes
- Fixed drink preview showing while empty-handed
- Fixed TWT native HUD not being hidden
- Fixed Nourishment/SatiatedShield effect retrieval
